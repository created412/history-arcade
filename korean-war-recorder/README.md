# 지도로 보는 6·25 전쟁

![지도로 보는 6·25 전쟁](assets/thumbnail.jpg)

지도로 따라가는 6·25 전쟁의 전개와 사람들의 이야기. 고등학교 『한국사』 72~73·88~91쪽을 바탕으로 만든 약 30분 분량의 수업용 인터랙티브 게임입니다.

## 웹사이트
`site/` 폴더는 수업용·복습용·단일 파일 판을 고르는 표지 페이지와 두 게임 페이지입니다. 이미지·음성은 `site/data/`에 따로 두어 두 판이 함께 쓰며, 수업용은 학예사 음성(약 3.5MB)을 불러오지 않습니다. 정거장 서버가 이 폴더를 https://history-arcade.onrender.com/625/ 로 공개합니다. 다른 정적 웹 서버에 폴더째 올려도 됩니다.

## 실행
- `index.html` 하나로 동작합니다(이미지·음성·영상 내장, 인터넷 연결 불필요).
- 크롬 권장. 갤럭시 탭·노트북·전자칠판에서 전체 화면(⛶)으로 사용하세요.

## 모드
- **수업: 교사가 설명하며 진행** — 학예사 목소리 없이 교사가 설명합니다. `→` / `PageDown`(발표용 리모컨)으로 넘기고, `H` 키로 설명자료를 엽니다. 진행 기록은 저장하지 않습니다.
- **혼자 해 보기 (복습)** — 학예사 한서윤의 목소리 안내로 진행합니다. 진행 상황이 브라우저에 저장되며, 시작 화면의 「기록 지우기」로 지울 수 있습니다.

## 시간여행 역사(驛舍) 클리어 보상
마지막 「기록관 보고서」 화면이 열리면 정거장에 클리어 신호(`history-station:clear`)를 보냅니다. 정거장 밖에서 단독으로 열면 아무 일도 하지 않습니다.

## 장면 바로가기
주소 끝에 `#장=2&단계=5`처럼 붙이면 해당 장·단계부터 시작합니다.

## 자료 출처
교과서 사진·지도의 저작권은 원저작자에게 있으며 수업용으로 사용했습니다. 지형 자료는 Natural Earth, 인물 그림·음성 일부는 AI로 만든 상상입니다. 자세한 출처는 게임 시작 화면의 「만든 방법과 자료 출처」를 보세요.
